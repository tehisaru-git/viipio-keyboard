# Viipio keyboard v0.10.2 — Key pop-up

## Changes

- Press a character key to see a large, temporary preview of the **same letter, digit or symbol**. Shifted letters preview their uppercase form. The preview disappears on release, cancellation, a glide or when the existing long-press alternatives take over. It does not insert a character early, alter swipe recognition or change the editor's text.
- **Settings → Preferences → Key pop-up** is ON by default and can be switched OFF without disabling typing or long-press choices. The choice survives a process restart. The existing adjustable touch-and-hold duration remains separate (300 ms by default).
- Controlled keyboard comparisons also covered number/symbol keys and a synthetic password editor. Viipio shows only the pressed key's label there; its password-field suggestion and diagnostic exclusions are unchanged.

## Verification and limits

The signed ARM64 APK has App ID `io.github.tehisaru.viipio`, versionName `0.10.2`, versionCode `10022` and SHA-256 `c316b2179917d07266bde4922b6d3c596754b3bd96009c2befea5377145a57e2`. It uses the same release-signing certificate as v0.10.1 and adds no INTERNET or RECORD_AUDIO permission. Its 70 packaged assets are byte-identical to the publicly downloaded v0.10.1 APK.

Full guarded JVM run: **5,715 tests across 539 suites, 0 failures/errors, 13 skipped**; Viipio Python checks: **47 passed**. On the installed signed APK, a controlled ET editor showed the large key preview and exact `sasa` input. The toggle was observed ON, OFF and ON again after process restarts; with OFF, exact typing still worked and no preview appeared in the sampled frames. EN Shift typing returned exact `saA`; symbol and digit inputs returned exact `2@2@`, and separate pressed-key screenshots showed their enlarged labels. Long-press `m` still committed one `?` and an EN glide still committed `sa`. A disposable password editor displayed the transient key preview while keeping eight synthetic characters masked and showing no word suggestions.

This is an experimental, emulator-tested release. Video frames do not prove precise popup duration; physical-device touch feel, extreme-font ergonomics and human swipe accuracy have not been measured. Keep another keyboard enabled and check important text. A secure off-host backup of the long-lived signing key has not been confirmed.
