# Viipio keyboard v0.9.1 — experimental emoji-browser update

**Offline Estonian (ET) and English (EN) keyboard.** This ARM64 APK updates Viipio v0.7.0–v0.9.0 (`io.github.tehisaru.viipio`) in place with the same signing certificate; it does not update the older `io.github.tehisaru.estonianswipe` app from v0.6.0 or earlier. Keep Gboard or another keyboard enabled while testing.

- Browse one vertically scrolling emoji catalog; the highlighted category follows the visible section, and tapping a category jumps there.
- Show one representative per packaged skin-tone family. Hold a hand to choose neutral or one of five tones. Mixed-person ZWJ emoji families expose **all existing catalog variants** in a scrollable picker. Uniform selections carry to other compatible hands. Search remains offline and separate.
- Use eight unboxed cells per ordinary emoji row, two wider cells for long kaomoji in its browse section, and a larger original emoji icon in the existing bottom-row key bounds. Popup touches, editor-confirmed recents, storage exceptions and viewport preservation have regression tests. No Google code, assets or model is included.

**Checks:** 42 Viipio Python tests and 5,629 JVM tests across 530 suites passed with 0 failures/errors and 13 skipped. The signed APK installed over v0.9.0 (ARM64 versionCode 9002→9012) on an Android 15 emulator. A local no-network editor verified category scrolling, a chosen 👋🏾, two consecutive emoji, browse Backspace, ABC and actual `IME_ACTION_SEND`; light/dark screenshots were inspected. The test editor/debug app were removed, and the previous Gboard/Home/day-mode state restored. The APK requests no Internet or microphone permission.

**Limits:** The layout is Gboard-inspired, not pixel-identical or guaranteed identical across devices. Long kaomoji may still look cramped in the generic search/recent grid. Physical Pixel 8 / GrapheneOS touch behavior, accessibility-service interaction, performance and third-party editors have not been validated. Check important text before sending. A secure off-host backup of the release signing key is not yet confirmed.
