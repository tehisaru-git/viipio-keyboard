# Viipio keyboard v0.10.0 — release verification

**Published GitHub Release:** [v0.10.0](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.10.0) is the current normal/latest release, not a draft or prerelease. Android App ID remains `io.github.tehisaru.viipio`; active input languages are Estonian (ET) and English (EN). The v0.9.1 release and APK remain available unchanged.

## Scope

- Removed only the exact ET dictionary form `sis` from the bundled CKDT V2 asset. Original 95,000 entries → 94,999; every remaining canonical word, rank and normalized lookup stays intact. `siis`, `sisu`, `sisse` and EN `sis` are unaffected. A separately imported older ET pack or user-added personal entry is not rewritten by this migration. Source is the hash-pinned pre-change Git binary; see `scripts/estonian/remove_sis.py`. The derived ET binary SHA-256 is `e5b6bc41df85a636d6892e51e2e0ef45a1a79990a0e0c9c326244b76b64d51a1`; this is **not** an APK checksum.
- For ordinary nonsensitive fields only, the active Viipio service can promote an existing *swipe* candidate over the decoder's first word when the scores are close enough. English has a bounded signal from listed bigrams in the already shipped `en.cklm`; this model is loaded off the UI thread. Estonian's new `et.cklm` has passed an in-domain next-word heldout gate but is **not enabled for automatic swipe top-1**: no ET corpus-based swipe accuracy claim is made. Both engines share the same post-decode policy; no new candidate is synthesized. Original scores and language labels remain paired with their words.
- Optional local preference from **explicitly selected swipe alternatives** is default OFF and accessible under Settings → Corrections. A pair is learned only if the **very next action is a successful Space**, and exact `selected word + space` with the next caret is read back from the same editor. A failed Space, next swipe/letter, field/cursor/language change or Undo discards the provisional choice. Erasure and OFF→ON transitions invalidate older pending choices through durable revisions. Two net confirmed choices are required before a closely scored rival can become top-1. Pairs are ET/EN-scoped in a bounded, credential-protected private preference file excluded from backup/transfer. The UI provides opt-out and explicit erasure. No raw swipe trace or editor context is saved by this feature. Existing opt-in diagnostics remain separate.
- Manual suggestions keep the existing prefix and edit-distance candidates, but in ordinary ET/EN fields the corresponding listed CKLM continuation can reorder **only those already offered choices**. An exact keyboard-typed word is never changed until the user taps a suggestion. Model-unavailable and private fields retain the previous ordering. No personal correction store is consulted on each typed letter. The ET corpus, licences, attribution and next-word-only heldout gate are documented in [the ET model report](../research/viipio-et-static-lm.md). The [bounded comparison](../eval/viipio-v010-ranking-design.md) concerns observed behavior only.

Rebuilding the pinned ET model yields the same 173,629-byte SHA-256 `f560e7424f867818692a0a2f574ae4c1155e8b3a6983f25795c6109cb3006712`. - **Full JVM gate:** `python3 scripts/viipio-check.py full` finished with **537 suites, 5,678 tests, 0 failures, 0 errors, 13 skipped**, `BUILD SUCCESSFUL in 12m 43s`. A focused field-exit regression was red 1/1 before its fix and green 1/1 after; the view-recreation and exact-Space proof were added subsequently and are included in this full run. Skips are not successes.
- **Fixed synthetic replays (not human accuracy):** six EN key-centre CTC cases decoded; same-slate top-1 changed 5→6, top-3 stayed 6→6, one correction and zero regressions under the predeclared contexts. ET `töö`/`too` collide on the CTC a–z path, so both spellings are not guaranteed simultaneous alternatives. These are narrow, generated paths, not a population accuracy estimate.

## Limitations

The previous user-authorized ET diagnostic export (572 accepted gestures) was held in an ephemeral document cache and is no longer on this host. No human-gesture accuracy delta can be claimed from it. The 0.65 minimum score ratio and bounded context/personal boosts are experimental until installed-editor and further real-gesture evidence are available; they must not be described as established accuracy improvements. The **bundled** Leipzig/Tatoeba ET model is enabled only for typed suggestions: its same-source next-word heldout result does not establish automatic swipe-ranking safety, so ET static swipe promotion remains disabled. Real-device touch precision, p95 latency, accessibility and other editors remain unverified. The long-lived release key stays outside Git and a secure off-host backup has not been confirmed.
