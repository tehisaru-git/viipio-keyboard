# Viipio keyboard v0.9.0

Experimental offline Android keyboard with separately selected Estonian (ET) and English (EN). Keep another keyboard enabled while testing.

## Emoji browse

- The emoji browser now has a real **Backspace** for text in the active editor instead of the misleading **Clear** control, which previously erased only emoji history. Two emoji can be chosen in succession without closing the browser; one browse Backspace removes the last one.
- Variation-selector emoji such as `❤️`, skin-tone emoji, joined emoji and flags are deleted as visible units when the editor provides enough context. An uncertain, truncated editor readback can safely decline rather than delete the wrong range. Search-query Backspace still edits only the search query.
- **ABC** returns to letters. In a Send-enabled editor, the ordinary keyboard's Send key invokes the actual editor action; there is no fake Send button in the emoji pane.
- **Privacy & diagnostics → Clear recently used emoji** offers a separate confirmed way to erase Viipio's local emoji history. It does not delete text in other apps or separately consented diagnostics.

These choices follow a bounded observation of Gboard on one Android 15 emulator and a synthetic local-only Send editor, **not** copied Google code, artwork or a claim about every Gboard setup. See the [observation](https://github.com/tehisaru-git/viipio-keyboard/blob/v0.9.0/docs/research/gboard-emoji-observation.md) and [verification record](https://github.com/tehisaru-git/viipio-keyboard/blob/v0.9.0/docs/releases/v0.9.0.md).

## Install, checks and limits

Install **`ViipioKeyboard-v0.9.0-arm64-v8a.apk`** over v0.7.0/v0.8.0 without uninstalling. The signed ARM64 APK has App ID `io.github.tehisaru.viipio`, versionCode `9002`, SHA-256 **`8661e4ddebad5349024d48ce9e844ae35cd71cafe11e04de8f779d1df2941ecf`** and the same certificate as the downloaded v0.8.0 APK (certificate SHA-256 `4cb4830a8f0832481ecb91dfdfc6f620da5f0f155b6afdc199a40589ff478838`). Android accepted an in-place 8002→9002 upgrade on the emulator. v0.6.0 has a different App ID and does not update in place. Check settings and personal words after updating on your own device.

The v0.9.0 source passed **5,609 JVM tests, 0 failures, 0 errors, 13 skipped** across 530 suites, plus 42 Viipio Python tests. A synthetic installed editor confirmed two emoji picks, browse Backspace, `süda` search with query Backspace, whole `❤️` deletion and ABC→actual `IME_ACTION_SEND` (action ID 4); the app did not send a network message. The privacy confirmation removed local recents on reopening. Gboard/Home were restored and the disposable editor app was uninstalled. The signed APK verified with `apksigner` and requests no Internet or microphone permission; diagnostics remain separately opt-in.

Physical Pixel 8 / GrapheneOS finger accuracy, battery/performance, other Android Unicode versions and behavior in third-party editors are **not yet measured**. Keep Gboard or another fallback keyboard and review important text before sending. A secure off-host backup of the private release signer is not confirmed.
