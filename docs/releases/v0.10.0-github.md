# Viipio keyboard v0.10.0 — experimental ET/EN ranking update

## Changes

- The bundled Estonian word list no longer contains the exact rare form `sis`. Only that one of the previous 95,000 entries was removed; `siis`, `sisu`, `sisse` and the English dictionary remain. An explicitly installed older ET pack or user-entered personal word is not rewritten.
- English swipe results may use the already included offline English bigram model to promote a *closely scored existing alternative* after a previous word. This is a limited post-decode decision, not a new recognizer, a guarantee of correct first choice or a claim about Gboard internals.
- An optional, default-OFF **Learn from my swipe corrections** control under Settings → Corrections stores a limited, language-separated preference only when a deliberately selected swipe alternative is followed **immediately by a successful Space** and exact editor readback. A single choice cannot change the top result. Undo, a failed Space, another swipe/letter, field/cursor/language changes and sensitive fields do not teach; turn it off or choose **Forget swipe preferences** to erase the local pairs. No raw swipe paths or editor context are stored by this feature.
- Existing typed-word suggestions may be reordered by a matching ET or EN offline bigram model, but typed text is never automatically replaced. A compact Estonian model was built from pinned Leipzig/Tatoeba sequential texts; its training attribution is bundled and its same-source heldout next-word test passed. It is **not** used to auto-promote Estonian swipe top-1: that needs separate held-out gesture validation.
- Recognition remains fully on-device. Active input languages are Estonian and English; this update does not add other language layouts or downloads.

## Verification and limits

- Full JVM gate: **5,678 tests across 537 suites, 0 failures/errors, 13 skipped**. Fixed nonpersonal CTC replays: EN same-slate top-1 5→6; ET top-1 5→5 (no ET static swipe promotion). These are synthetic checks, not human-gesture accuracy.
- Signed ARM64 APK: `ViipioKeyboard-v0.10.0-arm64-v8a.apk`, SHA-256 **`76278cf2f8dba82d7c1b8c9fb90aa419201f3ddc858558391b6d0d8eeeb94e28`**, App ID `io.github.tehisaru.viipio`, versionCode `10002`. The signing certificate matches v0.9.1; the APK installed in place over v0.9.1 on an Android emulator. Controlled ET and EN tap/swipe→Space paths, candidate replacement, Settings consent/erasure, and an Android password editor were checked. No INTERNET or RECORD_AUDIO permission is requested. See [the evidence report](<https://github.com/tehisaru-git/viipio-keyboard/blob/main/docs/releases/v0.10.0.md>).
- Synthetic key-centre paths and an in-domain next-word heldout corpus **do not** measure your own viibete or physical phone accuracy. The earlier private ET diagnostic export is no longer on this host, so this release does not claim a measured human top-1 accuracy gain. Physical Pixel 8 / GrapheneOS touch, latency and third-party editors remain unverified.
- App ID stays `io.github.tehisaru.viipio`. An in-place update needs the previous Viipio release signer. The long-lived key is not in the repository; an off-host backup has not been confirmed.

Source, licence notices and reproducible ET dictionary/model transforms are in this repository. The APK is available as the single asset on this GitHub Release; it is not attached in Discord.
