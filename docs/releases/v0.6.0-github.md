# Viipio keyboard v0.6.0 — experimental test release

**For testing, not a production-quality keyboard.** Keep Gboard or another keyboard installed. Estonian swipe accuracy, touch timing and stability have **not** been measured by a human on Pixel 8 / GrapheneOS. Check important text before sending.

## New since v0.5.1

- Explicit **Add to Estonian/English words** action for a word typed entirely with Viipio keys, with immediate Undo. No automatic learning or change to default swipe ranking.
- Three independent, initially **OFF** diagnostic consents: Estonian swipes, confirmed manually typed Estonian words, and confirmed Viipio-owned ET/EN input events. Only known actions in ordinary fields are eligible; PIN/password, email, URL, private/no-learning and numeric fields are excluded. A verified swipe Undo followed by a key-typed replacement can be linked in JSONL; uncertain cases remain unlinked.
- Gboard-inspired, original PIN/number/decimal/signed/phone/date/time layouts selected by the editor's Android input type. PIN shows digits only. Numeric editors hide word suggestions.
- Nonpersonal Swipe study prompts for `siis`, `sis`, `mhm` and `mhmh`.

## Privacy and test limitations

- Local-only processing; the APK requests no Internet or microphone permission. Diagnostic records are encrypted in app-private no-backup storage, with limited retention. **Export JSONL file** writes readable plaintext to a document *you choose*: it can contain personal text, and a failed export may leave a partial file. Review before sharing; delete exported copies yourself. **Stop all diagnostics** disables new collection, and **Erase local data** deletes local records/keys, not exported copies.
- The broad Android JVM regression suite is **RED: 5,591 tests, 41 failures, 13 skipped**. The same 41 failing test identifiers also failed in the previous v0.6 run and overlap inherited v0.5.1 failures; this does **not** mean every behavior is safe. The 151 active-path scoped Android tests and 32 Python guards passed. An installed signed ARM64 APK was checked with synthetic swipe → Backspace or glide-delete Undo → manual correction → linked JSONL export, Stop/Erase/restart, and zero retained events after typing in a numeric PIN field. This is not a real-finger quality or all-app privacy benchmark.

Download the **single ARM64 APK** `ViipioKeyboard-v0.6.0-arm64-v8a.apk` for Pixel 8. It retains package `io.github.tehisaru.estonianswipe`, versionCode `6002` and the v0.5.1 developer signing certificate. Obtainium can follow the repository URL `https://github.com/tehisaru-git/viipio-keyboard`. Do not install a debug or upstream CleverKeys APK in place of it.
