# Viipio keyboard v0.10.1 — simpler personal words (ET/EN)

## Changes

- While typing a new word with Viipio's own keys in an ordinary text field, use **+ Add “word” · ET/EN** beside the existing three horizontally scrollable suggestions. One deliberate tap saves the exact word in the selected language without changing what you typed. **Added … · Undo** reverses it. The earlier after-Space Add row remains available when applicable.
- The first eligible offer shows a short, nonblocking tip about Add and Undo. Settings → Languages & personal words keeps the instructions and the manual ET/EN add/list/remove controls available afterward.
- Typing, Space, the tip and ordinary suggestions **do not** automatically save words. Sensitive/private, no-personalization and unsupported fields cannot offer or save them. The existing separate swipe-correction learning choice remains default OFF. New personal words and the tip flag stay local and are excluded from automatic backup/transfer.
- Active input languages remain **Estonian (ET)** and **English (EN)**. The App ID is unchanged: `io.github.tehisaru.viipio`. Recognition is on-device; no INTERNET or RECORD_AUDIO permission is introduced by this feature.

## Verification and limits

The signed ARM64 APK is `io.github.tehisaru.viipio`, version `0.10.1` (`versionCode=10012`), SHA-256 `4428364692742795414caf2d2c8560fe4d11f0461608d3fab428ecd5ea12af19`. Its 70 packaged assets match tracked sources or deterministic regeneration. The final source passed 5,707 JVM tests across 539 suites (0 failures/errors, 13 skipped) and 45 Python checks. On the installed signed APK, controlled ET and EN words passed exact Add → Undo without altering editor text; ET also passed the after-Space fallback. Installed password, incognito and no-personalized-learning editors showed no Add/Undo, and Settings retained the instructions. A fresh-data **debug** install independently displayed the one-time nonblocking popup above the unchanged keyboard; this one-time state was not replayed on the already-used signed release package.

This remains an experimental release. Synthetic editor checks do not measure human swipe accuracy, Pixel 8 touch/latency or third-party app behavior. The personal-word and guidance data stay local and are excluded from automatic backup; a secure off-host backup of the long-lived signing key has not been confirmed. If a storage write fails, Add/Undo remains retryable and never claims success, but Android can suppress its Toast error notice when notifications are disabled. A quick field switch before the first popup frame may consume the one-time flag; the instructions remain in Settings. The previous v0.10.0 release and APK are unchanged.
