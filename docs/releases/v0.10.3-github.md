# Viipio v0.10.3 — improved key-press feedback

The temporary key pop-up on the regular Estonian and English keyboard is now closer in size and distance to a **bounded Android 15 / Gboard 18.6.3 emulator observation**. This is not a claim of identical behavior on every Gboard version or phone.

- Letters, the regular number row and symbols show a larger character above the pressed key. A first-row digit can use toolbar space without losing the top of its bubble. The ordinary `2` and `e` are shown in the [synthetic screenshot](https://github.com/tehisaru-git/viipio-keyboard/blob/main/docs/screenshots/v0.10.3-key-feedback.png).
- Dedicated numeric and PIN editors briefly shade the pressed key instead of displaying a floating digit, matching the reference observed in those editor types. This does not change the typed number.
- **Settings → Preferences → Key pop-up** remains on by default. Turn it off to remove the floating bubbles; ordinary typing and long-press options remain available. Numeric-editor pressed-key shading remains basic tap feedback.

**Install or update:** Use the [Obtainium instructions](https://github.com/tehisaru-git/viipio-keyboard#install-with-obtainium) or install the single signed ARM64 APK attached to this release. The package ID is `io.github.tehisaru.viipio`; it upgrades v0.10.2 in place. Keep a second keyboard available while evaluating an experimental keyboard.
