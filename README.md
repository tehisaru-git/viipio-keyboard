# Viipio keyboard (experimental)

**Viipio keyboard** is an experimental, offline Android keyboard with its own drawn interface and CleverKeys-derived CTC/geometric swipe recognition. The current preview supports Estonian (ET) and English (EN) typing; the product name does not limit future language support. Licensed under GPL-3.0; [CleverKeys](https://github.com/tribixbite/CleverKeys) is credited in [NOTICE](NOTICE) and its original README is [archived here](UPSTREAM_README.md). No Gboard code, model, artwork or word list is included. The app was previously called **Estonian Swipe**; the package ID `io.github.tehisaru.estonianswipe` and release-signing certificate remain unchanged so existing installations can update in place. The product name is a user-selected brand, not a declaration of trademark clearance.

**v0.6.0 is an experimental public test release**, not a dependable daily-keyboard release. Its ARM64 APK can update v0.5.1 in place; Pixel 8 / GrapheneOS typing quality is still unmeasured. The broad JVM suite is red (**41 failures among 5,591 tests, 13 skipped**); those 41 failing identifiers also occurred in earlier runs, but that does not prove every behavior correct. Keep another keyboard installed and review important text before sending. The following v0.6.0 features have scoped tests and synthetic emulator checks, not a physical-device accuracy benchmark. The app icon and keyboard gear open one English-language Settings home. Double-space punctuation, post-swipe spacing, manual suggestions, word deletion gestures, Backspace undo and corner symbols have active switches. Short suggestions spread across their row; only words that do not fit cause horizontal scrolling. You can add and remove ET/EN personal words locally (for example, `mhm` in ET). No unverified chat slang or English-in-ET pack was enabled by default. The independently drawn layout follows the user-supplied Gboard reference without copying its assets. Emoji browsing/search remains offline. Real-finger Estonian top-1/top-3 accuracy, latency, ergonomics, battery use and physical Pixel 8 visual alignment have **not** been measured. Keep another keyboard installed; check important text before sending. The [Gboard feature map and prioritized Viipio milestones](docs/plans/viipio-gboard-parity.md) distinguish the active IME from dormant CleverKeys modules and do not claim measured feature-use frequencies.

**New in v0.6.0 (not in v0.5.1):** A fully key-typed, unknown word followed by a literal Space can display a one-tap **Add to Estonian/English words** offer in the existing toolbar area; addition is explicit and has an immediate Undo. Optional, separately consented Estonian manual-word diagnostics remain OFF by default and store only verified completed words, not every keystroke. The export has distinct manual rows and versioned swipe rows with aligned candidate display scores and the actual decoder route where available. The fixed, nonpersonal Swipe study now includes `siis`, `sis`, `mhm` and `mhmh`. No default swipe rank or bundled chat lexicon was changed: available speech-corpus evidence does not establish redistribution-safe *chat* frequency for a general pack.

**New in v0.5.1 (not in v0.5.0):** Letter alternatives appear after 300 ms by default, with an adjustable duration in Preferences. The emoji pane stays open after each choice; tap **ABC** to return to letters. Shift now changes visible letter labels; a second quick Shift enables Caps Lock in unit tests. **Capitalize sentence starts** is a separate, default-OFF preference; installed emulator tests confirmed lowercase when off, `Aa` at the start when on, and `A. B` after a sentence boundary. ADB double-tap did not reliably trigger Caps Lock in the installed keyboard or reference Gboard, so physical-finger timing remains unverified. This release does not claim French typing support.

## Install or update on Pixel 8

1. Download **`ViipioKeyboard-v0.6.0-arm64-v8a.apk`** from the [experimental v0.6.0 GitHub Release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.6.0), or add `https://github.com/tehisaru-git/viipio-keyboard` in Obtainium's **Add App** screen to follow published releases. The [previous v0.5.1 APK](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.5.1) is `ViipioKeyboard-v0.5.1-arm64-v8a.apk`. Keep Gboard or another keyboard installed; do not choose a debug APK or upstream CleverKeys APK.
2. Android may ask whether the app used for the download is allowed to install packages. Open **Viipio keyboard → Keyboard setup & practice**, choose **Enable keyboard** and **Select keyboard**. Keep Gboard or your previous keyboard installed for a quick switch back.
3. For the published v0.5.1, use **ET/EN in the toolbar** for separate Estonian and English recognition. The Estonian and English word lists are bundled; the old v0.1.0 `langpack-et.zip` import is **not required**. While typing a word, tap one of the three dictionary completions to replace only that word; nothing is automatically corrected, and suggestions are hidden in sensitive or unsuitable fields. Hold a letter for its small corner symbol (`m` → `?`; `g` → `&`) or slide across a multi-choice popup (`g` also offers `ğ` and `ǵ`). Estonian `s`/`z` retain `š`/`ž` and offer `#`/`*`. Complete suggestions stay on one row, which moves sideways only if they do not all fit. To add `mhm`, open **Viipio Settings → Languages & personal words**, choose **Estonian (ET)** and tap **Add word**; delete it from the same list. The word is not copied into EN automatically. The **Preferences** page also lets you turn off double-space period insertion. After a swipe, the first manually typed letter normally receives a preceding space; to disable it, open keyboard **⚙ → Preferences → Add space after a swipe when typing**. Use `?123` for symbols and the emoji key to browse or search offline. Backspace hold repeats, a short leftward swipe deletes a word, and one Backspace tap immediately after a swipe deletes that word. To record optional **Swipe diagnostics**, open **Viipio Settings → Privacy & diagnostics → Swipe diagnostics → Start local collection** and confirm the consent dialog. Stop or erase from the same screen; **Export JSONL file** saves a readable file only where you choose. Diagnostics does not guess that an older selected word belongs to an earlier swipe; a user-declared marking action is planned separately. See [privacy and USB instructions](docs/eval/local-swipe-diagnostics.md).

The app ID is `io.github.tehisaru.estonianswipe`; v0.6.0 ARM64 uses versionCode `6002` (v0.5.1: `5012`). The private developer signing key is outside Git. Confirm signed update compatibility in the [v0.6.0 release verification](docs/releases/v0.6.0.md) before relying on it; do not mix differently signed builds.

## Scope and known limits

- The active IME is `EstonianSwipeService`, with its own measured key surface, touch controller, suggestions and emoji panel. Legacy CleverKeys keyboard/view/settings code remains in the source during migration but is not the visible keyboard.
- Swipe, dictionaries and emoji search run locally. The signed v0.6.0 APK requests **no Internet or microphone permission**. GIF search and voice input are not part of this preview. Three independent diagnostic consents (swipes, manual words and ET/EN input events) are **OFF by default**. App-private records are encrypted; a user-chosen JSONL export is readable plaintext and may contain personal text. Review it before sharing and delete copies when finished. No upload is implemented; password and numeric fields are excluded.
- An experimental 95,000-form Estonian lexicon is bundled and attributed to the [HeliBoard/Leipzig CC BY 4.0 source](docs/specs/estonian-offline-dictionary.md). Word-form coverage is **not** evidence of swipe accuracy. Updated language packs can still be imported through Settings.
- The v0.6.0 [release verification and limits](docs/releases/v0.6.0.md) cover explicit inline personal words, separately consented typed-word diagnostics, v1/v2 compatibility and fixed nonpersonal prompts. A general chat slang dictionary remains gated on licensed conversation-specific evidence and regression checks.
- The v0.5.1 [release verification and remaining limits](docs/releases/v0.5.1.md) cover the new hold delay, emoji-pane persistence, manual capitalization, opt-in sentence capitalization and the signed update path.
- The v0.5.0 [release verification](docs/releases/v0.5.0.md) covers the signed in-place emulator update, one settings home, ET-only `mhm` add/complete/delete, exact selected candidate readback, adaptive fit/overflow dragging and double-space ON/OFF editor results. New personal words are kept in credential-protected app storage and excluded from Android automatic backup; older legacy entries remain a separate compatibility input. See the [research/evidence note](docs/plans/viipio-v050-settings-and-lexicon.md) before treating a subtitle-frequency entry as popular in Estonian chat.
- The v0.4.0 release passed **73 scoped JVM tests and 12 Python checks**. A signed update was installed on the emulator: default-on and disabled swipe-to-manual spacing, the visible switch, long-word drag and a subsequent candidate tap were exercised in the practice editor; Gboard and the default-on switch were restored. See [v0.4.0 verification and limits](docs/releases/v0.4.0.md). The prior v0.3.1 launcher button opened diagnostics with collection still **OFF**, but no consented collection/export was performed in that check. The broad inherited CleverKeys suite reported legacy failures and was stopped after a worker out-of-memory cascade; it is **not** a passing full-suite claim. Physical-device typing, consented export/readback, privacy-editor coverage and performance tests remain open. See [human-swipe research](docs/eval/human-swipe-research.md), [emulator limits](docs/eval/emulator-test-reliability.md) and the [UI specification](docs/specs/estonian-swipe-ui.md).

## Source and reproducibility

The [Viipio identity guide](docs/branding/viipio.md) defines the app name, original icon, light/dark colors and update-compatibility checks. This repository is a GPLv3 **source snapshot**, based on CleverKeys commit `8335bd0`, not the upstream project's release history or F-Droid channel. The inherited `fastlane/` and `metadata/fdroid/` directories describe CleverKeys, not a Viipio listing. Third-party licenses and the offline emoji source are listed in [NOTICE](NOTICE). The upstream debug signing key and release/deployment workflows were intentionally excluded from this fork.

Build with Java 17 and Android SDK platform 34: `bash scripts/gradle-guard.sh assembleDebug`. The tracked English CKDT V2 dictionary at `scripts/dictionaries/en/en_enhanced.bin` is copied into the ignored production asset on a clean build; the bundled Estonian binary remains under `src/main/assets/dictionaries/`. A developer-signed release requires `RELEASE_KEYSTORE`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS` and `RELEASE_KEY_PASSWORD` outside Git; otherwise `assembleRelease` does not produce a publishable signed update. Do not publish an upstream or debug-key-signed release.
