# Viipio keyboard (experimental)

**Viipio keyboard** is an experimental, offline Android keyboard with its own drawn interface and CleverKeys-derived CTC/geometric swipe recognition. The current preview supports Estonian (ET) and English (EN) typing; the product name does not limit future language support. Licensed under GPL-3.0; [CleverKeys](https://github.com/tribixbite/CleverKeys) is credited in [NOTICE](NOTICE) and its original README is [archived here](UPSTREAM_README.md). No Gboard code, model, artwork or word list is included. The app was previously called **Estonian Swipe**; releases through v0.6.0 used the historical Android package `io.github.tehisaru.estonianswipe`. Beginning with v0.7.0, the neutral `io.github.tehisaru.viipio` package is a separate app and cannot update or silently migrate data from the old one. The product name is a user-selected brand, not a declaration of trademark clearance.

**v0.10.1 is a locally signed and tested candidate awaiting its own GitHub Release.** It adds a one-tap `+ Add “word” · ET/EN` action while typing, immediate Undo, a one-time in-keyboard hint and the existing after-Space fallback. The final candidate passed 5,707 JVM tests (0 failures, 13 skipped), 45 Python checks and synthetic installed ET/EN, password/private-field checks. It is **not yet the public download**; see its [candidate evidence and limits](docs/releases/v0.10.1.md).

**v0.10.0 is the current experimental public release.** Its [signed ARM64 APK](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.10.0) updates v0.7.0–v0.9.1 in place with the same App ID and signer; it does **not** migrate the old v0.6.0 app. It removes only the exact ET dictionary form `sis`, bounds EN context-based reordering to existing close-scored swipe candidates, and optionally learns from explicitly selected ET/EN alternatives after verified Space (OFF by default, erasable). A bundled ET model only reorders existing *typed* suggestions, not automatic ET swipe top-1. The signed emulator exercised ET/EN typing and glides, ET `sid`→`siis` candidate selection, the consent/erase UI and a password editor; 5,678 JVM tests passed with 13 skipped. None of this establishes physical-phone or human-gesture accuracy. See the [v0.10.0 verification](docs/releases/v0.10.0.md) and [release notes](docs/releases/v0.10.0-github.md).

**v0.9.1 is historical.** It introduced a continuously scrolling offline emoji catalog, section-following categories and packaged-tone long-press choices. Its [signed APK and verification](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.9.1) remain available; see [the original evidence record](docs/releases/v0.9.1.md).

**v0.9.0 is historical.** It added the emoji browse footer's editor Backspace, kept search-query deletion separate, and put confirmed recent-emoji erasure in Privacy & diagnostics. Its [verification record](docs/releases/v0.9.0.md) and [original APK](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.9.0) remain available.

**v0.8.0 is historical.** It added a more forgiving start near the number-row boundary, bounded earlier-word suggestions and background lexicon refresh after explicit personal-word Add/Undo. Its public [EKI frequency reference](docs/research/eki-enc21-common-word-forms.md) was research only, not a shipping decoder ranking. No exact Gboard internals are claimed.

**v0.7.0 is an experimental public test release and a new Android app, not an in-place update** of v0.6.0 or earlier. Its signed ARM64 APK is available through the verified release link below. The v0.7.0 broad JVM suite also remains **red** (**41 failures among 5,591 tests, 13 skipped**); its failing test identifiers match v0.6.0, but that does not establish identical causes or correctness. Keep another keyboard installed and review important text before sending. The features introduced in v0.6.0 carry forward; their earlier scoped tests and synthetic emulator checks are not a physical-device accuracy benchmark. The app icon and keyboard gear open one English-language Settings home. Double-space punctuation, post-swipe spacing, manual suggestions, word deletion gestures, Backspace undo and corner symbols have active switches. Short suggestions spread across their row; only words that do not fit cause horizontal scrolling. You can add and remove ET/EN personal words locally (for example, `mhm` in ET). No unverified chat slang or English-in-ET pack was enabled by default. The independently drawn layout follows the user-supplied Gboard reference without copying its assets. Emoji browsing/search remains offline. Real-finger Estonian top-1/top-3 accuracy, latency, ergonomics, battery use and physical Pixel 8 visual alignment have **not** been measured. Keep another keyboard installed; check important text before sending. The [Gboard feature map and prioritized Viipio milestones](docs/plans/viipio-gboard-parity.md) distinguish the active IME from dormant CleverKeys modules and do not claim measured feature-use frequencies.

**New in v0.6.0 (not in v0.5.1):** A fully key-typed, unknown word followed by a literal Space can display a one-tap **Add to Estonian/English words** offer in the existing toolbar area; addition is explicit and has an immediate Undo. Optional, separately consented Estonian manual-word diagnostics remain OFF by default and store only verified completed words, not every keystroke. The export has distinct manual rows and versioned swipe rows with aligned candidate display scores and the actual decoder route where available. The fixed, nonpersonal Swipe study now includes `siis`, `sis`, `mhm` and `mhmh`. No default swipe rank or bundled chat lexicon was changed: available speech-corpus evidence does not establish redistribution-safe *chat* frequency for a general pack.

**New in v0.5.1 (not in v0.5.0):** Letter alternatives appear after 300 ms by default, with an adjustable duration in Preferences. The emoji pane stays open after each choice; tap **ABC** to return to letters. Shift now changes visible letter labels; a second quick Shift enables Caps Lock in unit tests. **Capitalize sentence starts** is a separate, default-OFF preference; installed emulator tests confirmed lowercase when off, `Aa` at the start when on, and `A. B` after a sentence boundary. ADB double-tap did not reliably trigger Caps Lock in the installed keyboard or reference Gboard, so physical-finger timing remains unverified. This release does not claim French typing support.

## Install the neutral-ID app on Pixel 8

1. Keep Gboard or another keyboard enabled. If you used the old package, export only diagnostics you deliberately want to keep, review and safely store that plaintext file, and note any personal words you want to re-enter. A diagnostics JSONL export is **not** an app-data backup. Do not uninstall the old keyboard until you have tested the new one.
2. Download **`ViipioKeyboard-v0.10.0-arm64-v8a.apk`** from the [v0.10.0 GitHub Release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.10.0); its SHA-256 is `76278cf2f8dba82d7c1b8c9fb90aa419201f3ddc858558391b6d0d8eeeb94e28`. The [v0.9.1 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.9.1), [v0.9.0 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.9.0), [v0.8.0 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.8.0) and [v0.7.0 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.7.0) use the **same new App ID and signer** and can be updated in place. The [old v0.6.0 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.6.0) and [v0.5.1 release](https://github.com/tehisaru-git/viipio-keyboard/releases/tag/v0.5.1) (asset `ViipioKeyboard-v0.5.1-arm64-v8a.apk`) remain historical; they use the old App ID. In Obtainium, check whether the existing tracking entry remains bound to the old App ID. If it does, add a new entry for `https://github.com/tehisaru-git/viipio-keyboard`; if duplicate sources are refused, remove **only the old tracking entry (not the old installed keyboard)** and add the repository again. Confirm the downloaded APK and new entry identify `io.github.tehisaru.viipio`; the old package cannot update to this one. Do not install a debug or upstream CleverKeys APK.
3. If updating v0.7.0–v0.9.1, install **over** it without uninstalling; confirm your settings and personal words afterward. The emulator accepted the signed v0.9.1→v0.10.0 update and earlier v0.8.0→v0.9.0 and v0.9.0→v0.9.1 updates, but cross-version personal-word retention on your Pixel has not been independently checked. If coming from v0.6.0 or earlier, Android treats v0.10.0 as a **separate app**: open **Viipio keyboard → Keyboard setup & practice**, choose **Enable keyboard** and **Select keyboard**, and re-enter wanted settings/personal words. Test ordinary ET/EN typing in your apps before disabling any other keyboard. Diagnostics and the separate correction-learning control remain OFF unless explicitly enabled.

## Typing and diagnostics

Use **ET/EN in the toolbar** for separate Estonian and English recognition. The Estonian and English word lists are bundled; the old v0.1.0 `langpack-et.zip` import is **not required**. While typing a word, tap one of the three dictionary completions to replace only that word; moving the caret into an earlier word may also offer bounded one-edit alternatives, which replace the exact word only when explicitly selected and reverified. Nothing is automatically corrected, and suggestions are hidden in sensitive or unsuitable fields. Hold a letter for its small corner symbol (`m` → `?`; `g` → `&`) or slide across a multi-choice popup (`g` also offers `ğ` and `ǵ`). Estonian `s`/`z` retain `š`/`ž` and offer `#`/`*`. Complete suggestions stay on one row, which moves sideways only if they do not all fit. To add `mhm`, open **Viipio Settings → Languages & personal words**, choose **Estonian (ET)** and tap **Add word**; delete it from the same list. The word is not copied into EN automatically. The **Preferences** page also lets you turn off double-space period insertion. After a swipe, the first manually typed letter normally receives a preceding space; to disable it, open keyboard **⚙ → Preferences → Add space after a swipe when typing**. Use `?123` for symbols and the emoji key to browse or search offline. In emoji browse, the lower-right **⌫** deletes from the current text field; the search view's own ⌫ removes a query letter instead. **ABC** returns to letters, where a Send-enabled editor's actual Send key is available. To erase the local recently used emoji list (not text in other apps), use **Settings → Privacy & diagnostics → Clear recently used emoji** and confirm. On the ordinary keyboard, Backspace hold repeats, a short leftward swipe deletes a word, and one Backspace tap immediately after a swipe deletes that word. To record optional **Swipe diagnostics**, open **Viipio Settings → Privacy & diagnostics → Swipe diagnostics → Start local collection** and confirm the consent dialog. Stop or erase from the same screen; **Export JSONL file** saves a readable file only where you choose. Diagnostics does not guess that an older selected word belongs to an earlier swipe; a user-declared marking action is planned separately. See [privacy and USB instructions](docs/eval/local-swipe-diagnostics.md).

The current app ID is `io.github.tehisaru.viipio`; the previous package `io.github.tehisaru.estonianswipe` is historical and can coexist with it. v0.10.0 ARM64 uses versionCode `10002`, following v0.9.1 `9012`, v0.9.0 `9002`, v0.8.0 `8002` and v0.7.0 `7002` with the same Viipio signer. A package ID cannot be renamed in place: the v0.6.0→v0.10.0 transition does not automatically carry settings, personal words, diagnostics or keyboard selection. v0.7.0 introduced the **Viipio-named release-signing certificate**, retained through v0.10.0; old-package releases retain their historical signer. The private Viipio key stays outside Git and must still be backed up securely off-host for future updates. See the [v0.10.0 release verification](docs/releases/v0.10.0.md); never mix a debug or upstream-signed build with the published release.

## Scope and known limits

- The active IME is `ViipioInputMethodService`, with its own measured key surface, touch controller, suggestions and emoji panel. Legacy CleverKeys keyboard/view/settings code remains in the source during migration but is not the visible keyboard.
- Swipe, dictionaries and emoji search run locally. The signed v0.10.0 APK requests **no Internet or microphone permission**. GIF search and voice input are not part of this preview. Three independent diagnostic consents (swipes, manual words and ET/EN input events) and the separate correction-learning control are **OFF by default**. App-private diagnostic records are encrypted; a user-chosen JSONL export is readable plaintext and may contain personal text. Review it before sharing and delete copies when finished. No upload is implemented; password and numeric fields are excluded from swipe/personalization.
- An experimental 94,999-form Estonian lexicon (only `sis` removed) is bundled and attributed to the [HeliBoard/Leipzig CC BY 4.0 source](docs/specs/estonian-offline-dictionary.md). A separate attributed Leipzig/Tatoeba [ET bigram model](docs/research/viipio-et-static-lm.md) ranks existing typed suggestions but does not decide ET swipe top-1. Word-form coverage and an in-domain next-word heldout are **not** evidence of human-swipe accuracy. Updated language packs can still be imported through Settings.
- The v0.6.0 [release verification and limits](docs/releases/v0.6.0.md) cover explicit inline personal words, separately consented typed-word diagnostics, v1/v2 compatibility and fixed nonpersonal prompts. A general chat slang dictionary remains gated on licensed conversation-specific evidence and regression checks.
- The v0.5.1 [release verification and remaining limits](docs/releases/v0.5.1.md) cover the new hold delay, emoji-pane persistence, manual capitalization, opt-in sentence capitalization and the signed update path.
- The v0.5.0 [release verification](docs/releases/v0.5.0.md) covers the signed in-place emulator update, one settings home, ET-only `mhm` add/complete/delete, exact selected candidate readback, adaptive fit/overflow dragging and double-space ON/OFF editor results. New personal words are kept in credential-protected app storage and excluded from Android automatic backup; older legacy entries remain a separate compatibility input. See the [research/evidence note](docs/plans/viipio-v050-settings-and-lexicon.md) before treating a subtitle-frequency entry as popular in Estonian chat.
- The v0.4.0 release passed **73 scoped JVM tests and 12 Python checks**. A signed update was installed on the emulator: default-on and disabled swipe-to-manual spacing, the visible switch, long-word drag and a subsequent candidate tap were exercised in the practice editor; Gboard and the default-on switch were restored. See [v0.4.0 verification and limits](docs/releases/v0.4.0.md). The prior v0.3.1 launcher button opened diagnostics with collection still **OFF**, but no consented collection/export was performed in that check. The broad inherited CleverKeys suite reported legacy failures and was stopped after a worker out-of-memory cascade; it is **not** a passing full-suite claim. Physical-device typing, consented export/readback, privacy-editor coverage and performance tests remain open. See [human-swipe research](docs/eval/human-swipe-research.md), [emulator limits](docs/eval/emulator-test-reliability.md) and the [UI specification](docs/specs/estonian-swipe-ui.md).

## Source and reproducibility

The [Viipio identity guide](docs/branding/viipio.md) defines the app name, original icon, light/dark colors and update-compatibility checks. This repository is a GPLv3 **source snapshot**, based on CleverKeys commit `8335bd0`, not the upstream project's release history or F-Droid channel. The inherited `fastlane/` and `metadata/fdroid/` directories describe CleverKeys, not a Viipio listing. Third-party licenses and the offline emoji source are listed in [NOTICE](NOTICE). The upstream debug signing key and release/deployment workflows were intentionally excluded from this fork.

Build with Java 17 and Android SDK platform 34: `bash scripts/gradle-guard.sh assembleDebug`. The tracked English CKDT V2 dictionary at `scripts/dictionaries/en/en_enhanced.bin` is copied into the ignored production asset on a clean build; the bundled Estonian binary remains under `src/main/assets/dictionaries/`. For the new app, keep a long-lived Viipio release key and password in private, mode-0600 files under `~/.config/viipio-keyboard/`, **back them up securely outside this host**, then run `ANDROID_HOME=/path/to/android-sdk python3 scripts/sign-viipio-release.py`. The script uses the guarded offline Gradle build without printing secrets. Direct release builds without `RELEASE_KEYSTORE`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS` and `RELEASE_KEY_PASSWORD` do not produce a publishable signed APK. Do not publish an upstream, old-project or debug-key-signed release.
